# OpenVMS Field Notes

A one-page quick reference for OpenVMS newcomers: everyday DCL commands with Unix equivalents, file specifications, keys, user management, TCP/IP and SSH, plus notes for running OpenVMS x86-64 V9.2-3 under QEMU TCG on an Apple Silicon Mac.

It is a single static file, `index.html`, with no build step. Open it in a browser or serve it from any static host.

Features: a filter box to narrow the commands, click-to-copy on every command, and light and dark themes.
