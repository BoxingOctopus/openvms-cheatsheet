How VMS thinks

X86923::node DKA0:device [SYSTEM.NOTES]directory TODOname .TXTtype ;3version

A full file specification. You usually type only the parts you need: TODO.TXT means the newest version in your current directory. Your VM's node name is X86923.

Files have versions

Every save creates ;2, ;3, and so on. Nothing is overwritten. PURGE deletes the old versions, and DELETE needs a version number (;* for all of them).

Case-insensitive commands

DCL uppercases what you type. Commands and qualifiers can be shortened to any unique prefix: DIR, SH DEF, DEL.

Qualifiers use slashes

Options are /QUALIFIER or /QUALIFIER=value, e.g. DIRECTORY/SIZE/DATE. /NO… turns one off.

Wildcards

* matches any characters, % matches exactly one, and [...] searches every subdirectory below the current one.

Logical names

Named aliases for devices, directories or files, like SYS$LOGIN (your home) and SYS$SYSTEM. Use them anywhere a path goes.

Privileges, not root

Rights come from individual privileges (SYSPRV, BYPASS, CMKRNL…) granted to an account. SYSTEM has them all, so be careful as SYSTEM.

Symbols, logicals & scripts

Symbols are DCL variables and command aliases. Logical names are system-wide or per-process path aliases. Command procedures (.COM files) are DCL scripts, and every line starts with $.

CommandWhat it does
LL :== DIRECTORY/SIZE/DATEDefine a command alias. == makes it global; :== stores the text as-is.
SHOW SYMBOL *List your symbols.
DELETE/SYMBOL/GLOBAL LLRemove one.
DEFINE WORK SYS$LOGIN:[NOTES]Make a logical name for your process.
SHOW LOGICAL SYS$LOGINWhat a logical name points to.
DEASSIGN WORKRemove a logical name.
EDIT/TPU SYS$LOGIN:LOGIN.COMYour login script, run at every login. Put aliases here.

Users & passwords

Accounts live in SYSUAF, edited with AUTHORIZE. Start it with SET DEFAULT SYS$SYSTEM, then MCR AUTHORIZE. These commands go at its UAF> prompt.

CommandWhat it does
SET PASSWORD(At $) Change your own password at a no-echo prompt. Easiest for special characters.
SHOW SYSTEM(At UAF>) Show the SYSTEM account's settings.
SHOW */BRIEFOne line per account.
ADD RYAN/PASSWORD=temp1234/UIC=[200,201]/DEVICE=SYS$SYSDEVICE/DIRECTORY=[RYAN]/PRIVILEGES=(TMPMBX,NETMBX)/DEFPRIVILEGES=(TMPMBX,NETMBX)Create an ordinary user. Then create their directory (next row).
CREATE/DIRECTORY SYS$SYSDEVICE:[RYAN]/OWNER=[200,201](At $) The new user's login directory.
MODIFY SYSTEM/PASSWORD="New$Pass"/NOPWDEXPIREDSet a password without it being pre-expired. Quote it to keep case and special characters (needs /FLAGS=PWDMIX).
MODIFY SYSTEM/PWDLIFETIME=NONEStop a password from expiring.
MODIFY RYAN/FLAGS=DISUSERLock an account. /FLAGS=NODISUSER unlocks it.
REMOVE RYANDelete an account (not its files).
EXITLeave AUTHORIZE.

Admin, help & shutdown

CommandWhat it does
HELPBuilt-in help for every command. HELP SET DEFAULT drills in.
HELP/MESSAGE NOCOMDExplain an error code from a %FACILITY-L-CODE message.
EDIT/TPU SYS$MANAGER:SYSTARTUP_VMS.COMSite startup script: add things that should start at boot.
EDIT/TPU SYS$MANAGER:SYLOGIN.COMLogin script that runs for every user.
REPLY/ALL "Going down in 5 minutes"Broadcast to all terminals.
BACKUP [...]*.*;* DKA100:SAVE.BCK/SAVE_SETSave a directory tree into one backup file.
@SYS$SYSTEM:SHUTDOWNClean shutdown. It asks a few questions; the defaults are fine. Always do this before closing QEMU.

Message format: errors look like %DCL-W-NOCOMD, …, which is facility, severity, then code. The severity letter is S (success), I (information), W (warning), E (error) or F (fatal). - instead of % means a follow-on line of the same message.

Your VM on the Mac

These run in macOS Terminal, not in VMS, from ~/openvms.

CommandWhat it does
./boot-vms.shBoot with the SDL window. At BOOTMGR> type OPA0 then BOOT. Login takes 5–10 minutes.
ssh -p 2222 -o ConnectTimeout=120 system@127.0.0.1Log in over SSH once startup finishes.
telnet 127.0.0.1 2223Telnet fallback (unencrypted; fine on localhost).
ftp -P 2221 127.0.0.1FTP into the guest. Use bin for kits and binaries.
socat -,raw,echo=0,escape=0x1d UNIX-CONNECT:$HOME/openvms/console.sockSerial console (boot manager and early boot). Ctrl-] detaches.
tail -f ~/openvms/console.logFollow the serial console log.
echo "screendump /tmp/vga.png -f png" | socat - UNIX-CONNECT:$HOME/openvms/monitor.sock && open /tmp/vga.pngScreenshot the VM's screen.
echo "savevm vms-clean" | socat - UNIX-CONNECT:$HOME/openvms/monitor.sockSnapshot the running VM (guide Step 10). Restore by adding -loadvm vms-clean to the script.
echo "info status" | socat - UNIX-CONNECT:$HOME/openvms/monitor.sockIs the VM running or paused?

Avoid for now: HEADLESS=1 ./boot-vms.sh hangs VMS right after %GCDRIVER-I-INITDRV. Sending quit to the monitor is a hard power-off, so use @SYS$SYSTEM:SHUTDOWN inside VMS instead.
